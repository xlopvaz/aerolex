# MASTER PROMPT — CREACIÓN DE UNA PLATAFORMA WEB INTERNACIONAL DE APRENDIZAJE AERONÁUTICO

Quiero que actúes como un equipo multidisciplinar formado por:

- Un desarrollador web senior especializado en JavaScript, HTML5, CSS3 y arquitectura frontend.
- Un diseñador UX/UI especializado en plataformas educativas.
- Un experto en aviación comercial, operaciones aéreas y formación aeronáutica.
- Un especialista en terminología aeronáutica en inglés y español.
- Un instructor de formación de pilotos y tripulantes de cabina.
- Un especialista en meteorología aeronáutica, navegación aérea y comunicaciones ATC.

Tu misión es ayudarme a crear desde cero una plataforma web educativa, interactiva, moderna y completamente bilingüe (español e inglés), dedicada al mundo de la aviación.

El proyecto se desarrollará mediante GitHub y se publicará utilizando GitHub Pages.

Quiero construir una plataforma que combine las características de una academia aeronáutica, una enciclopedia, un diccionario técnico profesional, una biblioteca de consulta y un entorno de aprendizaje interactivo.

No quiero una página web convencional ni una simple landing page. Quiero desarrollar un proyecto ambicioso, con contenido real, herramientas funcionales y capacidad de crecimiento.

El público objetivo será internacional y estará formado por pilotos, estudiantes de aviación, tripulantes de cabina (TCP), profesionales del sector, aficionados a la aviación (AvGeeks) y personas que simplemente quieran aprender cómo funciona el mundo aeronáutico.

## 8.2 INTERACTIVE METAR DECODER

Esta herramienta es imprescindible.

El usuario podrá introducir cualquier METAR y la web debe:

1. Detectar sus grupos.
2. Separar automáticamente cada componente.
3. Identificar los códigos.
4. Explicar cada grupo.
5. Traducirlo al español o inglés.
6. Mostrar una interpretación completa en lenguaje natural.
7. Representar visualmente el viento.
8. Mostrar la nubosidad y altura de las nubes.
9. Interpretar visibilidad.
10. Mostrar temperatura, punto de rocío y presión.

Ejemplo:

LEMD 121830Z 24012KT 9999 SCT030 18/10 Q1013 NOSIG

Descompón el mensaje grupo por grupo.

El sistema debe detectar formatos incorrectos, mensajes incompletos y códigos desconocidos sin inventar interpretaciones.
