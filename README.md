# ✈️ AeroLex

**Learn the language of the sky.** · *Aprende el idioma del cielo.*

AeroLex es una plataforma web educativa, interactiva y completamente bilingüe (español / inglés) para aprender, consultar y explorar el mundo de la aviación. Combina una academia aeronáutica, un diccionario técnico, una enciclopedia de aeronaves y un laboratorio de herramientas (METAR/TAF, ATC, conversores…).

Está pensada para estudiantes de piloto, pilotos, TCP, profesionales del sector, AvGeeks y cualquier persona curiosa.

> ⚠️ AeroLex es un proyecto educativo. No sustituye la formación reglada, los manuales de vuelo, los manuales de operaciones del operador ni la documentación oficial vigente.
